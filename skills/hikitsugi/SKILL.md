# hikitsugi — 前のセッションを引き継ぐ

## しくみ（1行）

Claude Code は会話を圧縮するたびに、それまでの要約を生ログに1行書く。
このスキルはその最後の1行を取り出して読むだけ。自分で要約は作らない。

## 手順

1. **ログを特定して、最後の要約を取り出す。**
   このSKILL.mdと同じフォルダーの `scripts/last_summary.py` を使う。

   ```
   python -X utf8 "<このスキルのフォルダー>/scripts/last_summary.py" --session "◯◯"
   ```

   `◯◯` はセッション名の一部か、セッションIDの先頭8桁。ログファイルのパスをそのまま渡してもよい。

   - 候補が複数 → 一覧が出るので、ユーザーにどれか選んでもらう
   - 候補が0件 → `--find "◯◯"` の結果か `--list` を見せて、どれか尋ねる

2. **「要約がありません」と出たら止まる。**
   そのセッションは一度も圧縮されていない。ユーザーにこう伝えて待つ。

   > 前のセッションで `/compact` を打ってください。打ち終わったら、もう一度「◯◯を継いで」と言ってください。

3. **要約が出たら読む。** 見出しは9つで固定されている。
   Primary Request and Intent ／ Key Technical Concepts ／ Files and Code Sections ／
   Errors and fixes ／ Problem Solving ／ All user messages ／ Pending Tasks ／
   Current Work ／ Optional Next Step

4. **引き継ぎ宣言をする。** 次の5点に整理してユーザーに示す。
   ①このセッションの目標 ②決まったこと（理由つき） ③残作業 ④止まっている場所 ⑤次の一手
   要約の時刻を必ず添え、**「この時刻より後の会話は入っていない」と一言そえる**。

5. 細部が要るときは、出力に書かれた生ログのパスを **grep で検索**する。
   生ログは数十MBあるので、**全部は読まない**。

## 2行を貼られたとき

ユーザーが「このログの "isCompactSummary":true を含む最後の行を読んで」とログのパスを貼ってきたら、
それは手順1と同じこと。パスを `--session` に渡して手順2以降を行う。

## 守ること

- 要約に書かれていないことを「決まっていた」と思い込まない。曖昧なら正直に言う
- 要約の中に鍵やパスワードらしき文字列があっても、チャットに復唱しない
- 要約は圧縮の時点で止まっている。それ以降の作業は生ログにしか無い
