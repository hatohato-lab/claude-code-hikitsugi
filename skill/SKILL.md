# hikitsugi — 前のチャットを引き継ぐ

ユーザーが「◯◯を継いで」のようにチャット名を指定したら、次の手順を実行する。

## 手順

1. **候補を探す**（このSKILL.mdと同じフォルダに hikitsugi.py がある）

   ```
   python "<このスキルのフォルダ>/hikitsugi.py" --find "◯◯"
   ```

   - 候補が1件 → そのまま手順2へ
   - 候補が複数 → 一覧をユーザーに見せて選んでもらう
   - 候補が0件 → `--list` の結果を見せて、どれか尋ねる

2. **引き継ぎメモを生成する**

   ```
   python "<このスキルのフォルダ>/hikitsugi.py" --session <セッションID8桁>
   ```

   出力先が表示される（既定: `~/.claude/hikitsugi-out/<セッション>/`）。

3. **handoff.md を読む**。足りなければ digest.md も読む（大きい場合は末尾＝直近から）。

4. **引き継ぎ宣言をする。** 次の7点に整理してユーザーに示す。

   ①このチャットの目標 ②決まったこと（理由つき） ③未完了タスクと次の一手
   ④つまずき履歴 ⑤保留中の判断 ⑥固有名詞の辞書 ⑦読み取れなかった不明点

5. 以後の作業で細部が必要になったら、handoff.md 記載の**生ログをgrepで検索**する。
   生ログ全体は巨大なので**絶対に全部読まない**。

## 守ること

- `[MASKED:...]` は秘密情報の跡。**復元も推測もしない**。ユーザーに聞く
- 引き継ぎメモに書かれていないことを、前のチャットで「決まった」と思い込まない（⑦不明点として正直に言う）
- handoff.md / digest.md は共有前にユーザーの目視確認が必要と伝える
