# claude-code-hikitsugi

長くなった Claude Code のセッションを畳み、新しいセッションで続きから始めるためのスキルです。

圧縮（コンパクション）が作る要約には頼りません。
いまのセッションに残っている記憶と生ログから、引き継ぎ書を書き起こします。

## 目次

1. 導入（marketplace に足して install する）
2. 使い方（引き継ぎたい、と伝える）
3. 設計の理由（圧縮の要約に頼らない）
4. 構成（SKILL.md 1枚と設定のみ）
5. 制限（Windows の PowerShell が前提）
6. ライセンス（MIT）

## 1. 導入（marketplace に足して install する）

```
/plugin marketplace add hatohato-lab/claude-code-hikitsugi
```

```
/plugin install hikitsugi@claude-code-hikitsugi
```

## 2. 使い方（引き継ぎたい、と伝える）

いまのセッションで、次のように伝えます。

```
引き継ぎたい
```

以下の順に進みます。

1. このセッションの作業が、時間順の一覧で表示されます
2. 引き継ぐものを番号で選びます（すべて引き継ぐ場合は「全部」と答えます）
3. 選んだ分だけで引き継ぎ書が作られ、保存先のパスが表示されます
4. 新しいセッションに貼る2行が表示されます

新しいセッションでその2行を貼ると、続きから始まります。

## 3. 設計の理由（圧縮の要約に頼らない）

圧縮のたびに、判断の理由と細部が失われます。公式ドキュメントには次のように記載されています。

- 圧縮直後に読み直されるファイルは5件のみです。5,000トークンを超えるものは、中身を伴わないパスだけが戻ります
- 圧縮より前の思考は引き継がれません
- `paths` 付きのルールと、下位フォルダの CLAUDE.md は要約から失われます

出典は `skills/hikitsugi/SKILL.md` の7節に記載しています。

## 4. 構成（SKILL.md 1枚と設定のみ）

```
skills/hikitsugi/SKILL.md   スキル本体。これ1枚で動作します
.claude-plugin/             プラグインの設定
```

Python やスクリプトは使用しません。SKILL.md 1枚のみで構成されています。

## 5. 制限（Windows の PowerShell が前提）

- 生ログを読み出すコマンドが PowerShell のため、Windows を前提としています
- 生ログのパスは環境ごとに異なります。探し方は SKILL.md の3節に記載しています
